Manual de Arquitectura Cloud, Estándares de Código y Despliegue Continuo - Versión 6.0

Cláusula 1: Principios de Diseño de Microservicios

Todos los nuevos servicios deben implementarse bajo principios de alta cohesión, bajo acoplamiento y contenerización en Docker, garantizando compatibilidad con entornos Kubernetes.

Adicionalmente, se estipula que cada área involucrada deberá designar un responsable para la verificación continua de los lineamientos descritos en este apartado. Las excepciones temporales deberán ser tramitadas por escrito ante el Comité Directivo indicando los riesgos mitigados y el plan de contingencia asociado.

Cláusula 2: Estándares de Documentación y OpenAPI

Cada endpoint de API REST o gRPC debe contar con su especificación OpenAPI/Swagger documentada, incluyendo esquemas de solicitud, códigos de error HTTP y ejemplos de respuesta.
